# 저장소 공통 규칙 (cdj44y-ui)

이 저장소의 PR 양식과 이슈 양식은 계정의 모든 저장소에 기본값으로 적용됩니다.
저장소에 자기 양식이 있으면 그 저장소 양식이 우선입니다.

## 1. 병합하면 안 되는 PR은 초안(Draft)으로
미리보기·협의·승인 대기 PR은 초안으로 엽니다. 초안은 병합 버튼이 잠깁니다.
제목에 '병합 금지'라고 쓰는 것만으로는 막히지 않습니다.

## 2. 공개 사이트는 크기에 따라
- 글자 한두 줄 수정: main(또는 master)에 바로 올려도 됩니다.
- 화면·기능 변경: 브랜치 → PR → 미리보기 확인 → 대표님 "반영" → 병합.

## 3. 요청과 버그는 이슈로
고객 요청, 대표님 지시, 버그는 이슈로 남깁니다.

- 제목 앞에 종류를 붙이고 같은 이름의 라벨을 답니다.

  | 앞머리 | 라벨 | 뜻 | 예 |
  |---|---|---|---|
  | `[Bug]` | `type:bug` | 고장 난 것 | [Bug] 결제 완료 메일이 두 번 감 |
  | `[Story]` | `type:story` | 사람이 보고 쓰는 기능 | [Story] 상품 목록에 품절 표시 |
  | `[Task]` | `type:task` | 문서·도구·테스트처럼 뒤에서 하는 일 | [Task] 설치 안내 문서 정리 |

- 본문에는 대표님 말을 날짜와 함께 그대로 옮기고, 됐는지 안 됐는지 바로 가릴 목표를 한 줄로 적습니다.
- 화면이 바뀌는 일이면 「가짜 데이터로 찍은 PC, 폰 스크린샷 필요」라고 적습니다.
- 순서가 있는 일은 본문에 「#12 가 끝난 뒤 시작」처럼 적습니다.

## 4. 맡을 때는 라벨과 댓글로 「제가 합니다」
- 일을 시작하는 세션은 `status:in-progress` 라벨을 붙이고, 「이 세션이 맡았습니다」 댓글에 작업 브랜치 이름을 적습니다.
- 맡은 쪽이 내 컴퓨터 세션이면 `owner:local`, 클라우드 세션이면 `owner:cloud` 라벨을 붙입니다.
- 이미 `status:in-progress` 가 붙은 이슈는 다른 세션이 건너뜁니다.

## 5. 브랜치와 PR
- 작업은 새 브랜치에서 하고 PR 로 올립니다(2번의 글자 한두 줄 수정은 예외).
- PR 본문 맨 위 「연결된 이슈」에 이슈마다 한 줄씩 `Closes #번호` 를 적습니다.
  `Closes #1, #2` 처럼 한 줄에 몰아 쓰면 첫 번째만 닫힙니다.
- 기본 브랜치(main 또는 master)로 병합해야 이슈가 저절로 닫힙니다.
- 관련 있는 이슈는 묶어서 브랜치 하나, PR 하나로 처리합니다. 이슈마다 커밋을 하나씩 둡니다.
  이슈마다 세션을 하나씩 붙이면 합칠 때 충돌이 나서 오히려 느립니다.

## 6. 검토와 병합
- 이슈에 적힌 항목과 PR 결과를 한 줄씩 맞춰 「됨, 일부, 안 됨」 표를 만듭니다.
- 빌드가 깨지거나 보안 문제가 있으면 돌려보냅니다.
- 작은 빈틈 때문에 병합을 미루지 않습니다. 약 90% 면 병합하고, 남은 것은 새 이슈로 만듭니다.
  이미 닫힌 이슈는 다시 열지 않습니다.
- 병합은 대표님 "반영" 확인 뒤에 합니다(2번 규칙).

## 7. 먼저 묻는 일과 알아서 하는 일
기준은 하나, 「잘못돼도 되돌리기 쉬운가?」입니다.

| 알아서 하고 나중에 보고 | 대표님께 먼저 묻기 |
|---|---|
| 이슈 만들기·나누기·순서 정하기 | 돈이 드는 일 |
| 브랜치에서 고치고 PR 올리기 | 운영 서버에 반영 |
| 결과 확인, 후속 이슈 만들기 | 도메인·키 같은 계정 설정 |
| 문서·강의 자료 고치기 | 제품 방향을 바꾸는 선택 |
| | 고객에게 나가는 메일·문자 발송 |
| | 지우기(데이터, 저장소, 서버) |

## 8. 2주 넘게 멈춘 PR은 정리
병합하거나 닫습니다. 닫아도 브랜치는 남기고, 필요하면 다시 엽니다.

## 라벨
모든 저장소에 아래 라벨을 같은 이름으로 둡니다.

| 라벨 | 뜻 |
|---|---|
| `type:bug` | 고장 난 것 |
| `type:story` | 사람이 보고 쓰는 기능 |
| `type:task` | 뒤에서 하는 일 |
| `status:in-progress` | 세션이 맡아 진행 중 |
| `owner:local` | 내 컴퓨터 세션이 맡음 |
| `owner:cloud` | 클라우드 세션이 맡음 |
